# Known Limitations & Boundaries

1. **Scanned PDF OCR**: Requires Tesseract OCR binary installed on host machine; text-based PDFs and structured spreadsheets are processed natively.
2. **Bank Sync / Aggregators**: Real-time bank sync (Plaid/Setu) requires institutional production API keys; Financial Flow focuses on independent statement ingestion.
3. **Tax & Investment Advice**: The AI assistant provides analytical financial explanations and educational content, not regulated fiduciary investment advice.
